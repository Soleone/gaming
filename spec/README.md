# Gaming specification

A curated video-game release calendar with personal hype ratings and played reviews. Browse one year at a time, optionally narrowed to a month. See [maintenance](../docs/maintenance.md) for storage and development details.

Behavior uses stable `area.behavior` slugs. Tests begin their titles with the corresponding slug. Update the rule and tests together when behavior changes.

| `agent.research`    | A visitor asks the local agent to research a game                                                              | A local pi-durable conversation uses the configured pi-web-access search provider (including keyless Exa), or OpenAI hosted search through Pi login when no search provider/key is configured. Temporary failures on OpenAI or other routes get at most one retry, never for authentication or quota failures on the same provider. All attempts share the original timeout and cancellation; results identify the provider used, and errors identify the failure category without exposing raw responses. Source-linked results are verified against original pages; page reads include bounded navigation links and image candidates in page order with their alt text, taking full-size images from <noscript> over hidden blurred placeholders and the widest srcset or <picture> source over a small fallback src. | `agent.steps`       | The agent works on a reply                                                                                     | Consecutive assistant messages read as one reply. Each step's title states its status and subject: present tense while running, past tense when done, "Failed to …" on error. Steps with output expand to show it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `agent.cover`       | A proposal offers cover candidates                                                                             | Candidates preview as 16:9 tiles loaded from their source without a referrer, next to the current cover when the target has one; a failed preview shows a placeholder. Nothing downloads until the proposal is saved or opened in the form, and only the selected candidate of a completed proposal can be downloaded. Bounded JPEG/PNG/WebP still images at least 600px wide are re-encoded to content-named local WebP files; existing files are not overwritten. Selecting the current cover keeps the cover unchanged.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `agent.save`        | A visitor saves a proposal from the agent                                                                      | One action downloads the selected cover and writes games.json.
