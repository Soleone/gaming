# Gaming specification

A curated video-game release calendar with personal hype ratings and played reviews. Browse one year at a time, optionally narrowed to a month. See [maintenance](../docs/maintenance.md) for storage and development details.

Behavior uses stable `area.behavior` slugs. Tests begin their titles with the corresponding slug. Update the rule and tests together when behavior changes.

| Rule                | When                                                                   | Then                                                                                                                                                                                                                                               |
| ------------------- | ---------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `app.shell`         | The app opens                                                          | Soleone Gaming / What I'm excited about shows the calendar with month before year controls and the classic theme picker. Release sources remain in the editor/data, not the cards. No collection slogan appears in the footer.                     |
| `calendar.filter`   | A visitor selects a year or month                                      | Only games in that year and, optionally, with that known month are shown. Quarter/year/unknown dates are never guessed into months. Changing year resets the month.                                                                                |
| `calendar.order`    | Games share a month                                                    | Exact days sort chronologically, followed by month-only dates; ties sort by title.                                                                                                                                                                 |
| `release.precision` | A release has a day, month, quarter, year, or unknown date             | Its label preserves that precision. Exact dates use abbreviated English months (Oct 24, 2026), and month-only dates use Oct 2026. Quarter-only and unknown-month games have separate year-view sections. Games with no year appear in Unscheduled. |
| `data.valid`        | Game data is loaded or saved                                           | IDs are unique; dates exist; hype is null or an integer 1–5; played scores are null or an integer 1–10; links use safe web URLs or local cover paths.                                                                                              |
| `review.visibility` | A game has no played review                                            | Show Not played only on or after its exact release day, or after its entire month/quarter/year window ends, using the visitor's local date. Unknown dates never assert release. Played badges remain visible regardless of release date.           |
| `review.played`     | A game is marked played                                                | It may have a short review up to 1,000 characters and a score 1–10. Not played games have no review.                                                                                                                                               |
| `theme.initial`     | A visitor opens the app without a saved choice                         | Gilt is applied before the app renders, including its actual palette tokens.                                                                                                                                                                       |
| `theme.open`        | A visitor activates the theme control or presses T outside text fields | The classic theme picker opens on the current theme.                                                                                                                                                                                               |
| `theme.select`      | A visitor confirms a theme                                             | The page adopts the theme, closes the picker, and remembers the choice when storage is available.                                                                                                                                                  |
| `theme.toggle`      | A visitor presses D outside text fields or the picker                  | The page flips between dark and light, remembering the last choice on each side, with Gilt/Flexoki Light as fallbacks.                                                                                                                             |
| `editor.save`       | A visitor uses the local development editor                            | They can add, change, and remove games in src/data/games.json, including hype, played reviews, and date precision. Successful saves update the calendar.                                                                                           |
| `editor.conflict`   | games.json changes after the editor loads it                           | Saving is refused rather than silently overwriting the external change; the draft remains available.                                                                                                                                               |
| `editor.safety`     | A write is requested                                                   | Only the dev server exposes the endpoint. It requires loopback access, a loopback hostname, a same-origin request, and a per-server token. Invalid or oversized data never writes. Production has no editor or write endpoint.                     |
| `editor.draft`      | A visitor closes or switches games with unsaved edits                  | Discarding requires confirmation; save failures leave the draft intact.                                                                                                                                                                            |
